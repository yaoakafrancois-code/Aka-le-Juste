## Télécharger

| Fichier | Pour quoi faire |
|---|---|
| **Installer-CacaoCoop.exe** | Installer CacaoCoop sur un ordinateur Windows 10 ou 11 (double-clic, puis Suivant) |
| **CacaoCoop-android.apk** | Installer l'application sur une tablette ou un smartphone Android |
| **CacaoCoop-portable-windows.zip** | Utiliser CacaoCoop depuis une clé USB ou un disque dur, sans installation |
| **GUIDE_INSTALLATION.md** | Le guide d'installation pas à pas |

Au premier démarrage, un assistant demande les informations de la coopérative et crée le compte administrateur.

Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**,
puis sur **Exécuter quand même**. Sur Android, autorisez l'installation d'applications de cette source.
